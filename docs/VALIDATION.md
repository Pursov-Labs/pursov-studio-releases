# Проверка PURSOV STUDIO 2.0.0

Дата: 5 ноября 2026 года. Статус: предварительный выпуск.

## Выполнено

- Release-сборка без ошибок и предупреждений; автономный x64 MSI с .NET, Python и зафиксированными сетевыми компонентами.
- 13 групп самопроверок приложения: разбор стратегий, отмена, независимая остановка компонентов, состояние и настройки.
- Изолированные проверки парсера/процессов (5 групп), службы Telegram (3), Python runner (6), брокера (5), доверия обновлениям (21), ACL помощника установки (6).
- 20 проверок таблиц MSI: службы, ярлыки, порядок обновления/отката, комплектность и отсутствие пользовательских секретов.
- Сверка подписей, размера, версии и SHA-256 двух настоящих MSI: 1.9.99 и 2.0.0, включая отклонение понижения версии. Это проверка пакетов, а не выполненное обновление установленного приложения.
- 6 проверок представления состояния; проверки геометрии и 13 визуальных снимков WPF. Настоящее окно при 100% DPI, клавиатурный фокус, переход к сведениям о программе и возврат проверены через Windows UI Automation.
- Светлая/тёмная темы просмотрены; контрастные цвета проверены в ресурсах. Физическое переключение высокой контрастности и Narrator ещё не проверены.
- Исходники оболочки сверены с архивом; пять архивов исходников upstream проверены по зафиксированным SHA-256. Закрытый ключ и пользовательские данные исключены из публикации.
- Ручное ревью границы прав и обновлений: исправлены откат данных ProgramData, повторное использование неудачной транзакции, небезопасные существующие каталоги, запуск во время установки и порядок запуска помощника перезапуска.

Числа обозначают группы проверок; отдельные проверки могут пересекаться между наборами. Они не доказывают отсутствие всех ошибок.

## Нагрузка

10 минут, 16 логических процессоров, открытое окно интерфейса в режиме предварительного просмотра: средний CPU 0,00114%, максимальная приватная память 81,31 МиБ. В этом режиме `--signin` не скрывает окно, поэтому исходная отметка измерения «tray» была исправлена. Сетевые процессы, служба, трей и трафик в этот замер не входили. Полные пределы 0,5% CPU / 250 МБ для всех собственных процессов пока не подтверждены.

## Не завершено

- Чистая установка, перезагрузка/автозапуск, обновление, принудительный откат и удаление на Windows 10 22H2 и Windows 11.
- Проверка обычного пользователя с паролем другого администратора, двух сеансов, сна, смены сети и реальных конфликтов с другими установленными сетевыми средствами.
- Передача реального Telegram-сообщения, голосовой звонок Discord и длительное воспроизведение YouTube. UI различает запуск процессов, технические пробы и непроверенные пользовательские функции.
- Полный 10-минутный замер всех собственных процессов при подключении, отдельно в окне и трее, на одной тестовой системе.
- Физические масштабы 125–200%, перенос между мониторами, экран 1366×768 и Narrator.

Запрос UAC для доступа к локальной виртуализации был отменён; установленные пользовательские компоненты не заменялись. Защита Windows не отключалась. Defender заблокировал отдельно скачанный официальный архив WinDivert при дополнительном сравнении; поведение конечного MSI на чистых системах требует проверки.

Запуск плагина Codex Security завершился ошибкой «The selected scan target changed while the scan was starting». Канонического отчёта сканера нет; ручное ревью выше не выдаётся за результат Codex Security.

## Канал выпусков

Предварительные выпуски доступны для ручного скачивания. Автообновление приложения использует стабильный GitHub Release и не устанавливает предварительные версии. Пока стабильный выпуск не опубликован, установленная версия продолжает работать без предложения обновления.

Подпись манифеста проверяется встроенным публичным ключом. Она не заменяет Authenticode/репутацию SmartScreen для первоначального установщика.
