# PURSOV STUDIO

Открытая Windows-оболочка для подключения через Zapret и TG WS Proxy. Основной экран показывает состояние соединения и результаты проверок. Настройки, диагностика, журнал и обновления находятся в разделе «Подробнее».

## Источники и авторство

Сетевые компоненты основаны на открытых проектах Flowseal.

- [Flowseal / zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
- [Flowseal / tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)

PURSOV STUDIO добавляет установщик, управление процессами, интерфейс и проверку обновлений. Исходные проекты сохраняют авторство и свои лицензии. Оригинальный код оболочки опубликован под MIT. Лицензии зависимостей перечислены в [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

[Исходники и выпуски PURSOV STUDIO](https://github.com/Pursov-Labs/pursov-studio-releases)

В сборке зафиксированы версии и SHA-256 компонентов. Zapret берётся из официального релиза Flowseal, Telegram-прокси — из указанного коммита Flowseal. Сведения о происхождении находятся в `payload/zapret.lock.json`, `scripts/prepare-tg.ps1` и `payload/sources.lock.json`. Соответствующие архивы исходников сторонних компонентов публикуются вместе с выпуском.

## Установка

1. Скачайте MSI из раздела Releases и откройте его.
2. Подтвердите запрос прав Windows. Установщик включает .NET, Python и сетевые компоненты.
3. Откройте PURSOV STUDIO. Соединение включается автоматически. Первый подбор способа подключения может занять несколько минут, его можно отменить.
4. Нажмите «Настроить Telegram» и подтвердите прокси в Telegram. Это требуется один раз для вашей учётной записи.

Сборка предназначена для Windows 10 22H2 и Windows 11 на Intel/AMD x64. Результаты фактически выполненных проверок перечисляются в описании каждого выпуска. Работоспособность зависит от сети и доступности сторонних сервисов.

Приложение запускается при входе в Windows и остаётся в трее после закрытия окна. Эти настройки можно изменить в разделе «Подробнее». «Отключить» прекращает собственное соединение до следующего включения или запуска приложения. «Выход» в трее завершает приложение и его сетевые процессы.

Для запуска драйвера используется служба PURSOV STUDIO. Она работает по запросу приложения. Telegram-прокси работает от вашей учётной записи. Ранее запущенные экземпляры Zapret или TG WS Proxy нужно закрыть через их собственное меню.

## Обновления

Проверка запускается в фоне при открытии приложения, затем не чаще раза в сутки. Если GitHub недоступен, программа увеличивает интервал повторных попыток и продолжает работать с установленной версией.

Обновление загружается автоматически. Установка начинается только после кнопки «Установить». Приложение завершает своё соединение, обновляется и возвращается к предыдущему состоянию. При ошибке Windows Installer выполняет откат.

Каждый пакет проверяется по размеру и SHA-256. Манифест выпуска подписан отдельным ключом PURSOV STUDIO, публичная часть которого встроена в приложение. Закрытый ключ хранится отдельно от проекта. Эту подпись использует механизм обновления. Первичный MSI пока не имеет доверенной подписи издателя Windows, поэтому SmartScreen или политика компьютера могут показать предупреждение либо заблокировать запуск.

Согласованные версии Zapret и Telegram-прокси поставляются вместе с выпуском оболочки. Источники компонентов и версии доступны в разделе «О программе».

## Состояния и диагностика

«Подключено» означает, что собственные сетевые компоненты запущены. Результаты доступности сервисов показываются отдельно. Непроверенные функции остаются в состоянии «Не проверено».

Telegram проверяется начальным MTProto-обменом. Discord проверяется через API и Gateway. YouTube проверяется отдельно как сайт и небольшой видеофрагмент. Полные звонки, пользовательские сообщения и длительное воспроизведение требуют отдельной пользовательской проверки.

Полный подбор выполняется при первом подключении или по кнопке «Подобрать заново». При обычных запусках используется сохранённый способ. В фоне приложение отслеживает собственные процессы и редко проверяет доступность API. При отключённом соединении сетевые диагностические проверки прекращаются.

## Данные и удаление

- Файлы приложения находятся в `%ProgramFiles%\PURSOV STUDIO`.
- Защищённые сетевые компоненты и сведения об установке находятся в `%ProgramData%\PURSOV STUDIO`.
- Настройки текущего пользователя и ограниченный журнал находятся в `%LOCALAPPDATA%\PURSOV STUDIO`.

Секрет Telegram защищён Windows DPAPI для текущей учётной записи. При восстановлении повреждённых настроек исходный файл сохраняется с суффиксом `.backup-...`. Обновление сохраняет настройки. Удаление доступно через список установленных приложений Windows. Настройки прокси в самом Telegram остаются до их отключения пользователем.

## Сборка из исходников

Требуется Windows x64 и PowerShell 7. Скрипты получают зафиксированный официальный .NET SDK, Python, зависимости и исходники компонентов с проверкой контрольных сумм.

```powershell
pwsh -File scripts/build.ps1
pwsh -File scripts/package.ps1 -SkipBuild -NoReleaseSignature
```

Результат находится в `output/releases/<версия>/`. Повторная сборка с готовым Python runtime поддерживает `-SkipRuntime`. Номер версии читается из проекта, для тестового выпуска можно передать `-Version`.

Параметр `-NoReleaseSignature` собирает MSI без подписи манифеста обновления и позволяет собрать приложение без закрытого ключа официального издателя. Для собственного канала обновлений замените адрес репозитория в `ReleaseTrust.Repository`, удалите из своего форка `ReleaseSigningKey.cs` и создайте собственный ключ через `scripts/release-key.ps1 -Initialize`. Официальные клиенты PURSOV STUDIO принимают только выпуски, подписанные официальным ключом. Ключи и пользовательские данные в репозиторий не входят.

WiX используется только при сборке установщика. Его действующие лицензионные условия относятся к использованию инструментария разработчиком. Сторонние компоненты сохраняют свои условия распространения.

## Проверки разработчика

```powershell
$build = Get-Content output/last-build.json -Raw | ConvertFrom-Json
.tools/dotnet/dotnet.exe run --project tests/zapret-parser -c Release -- "$($build.Directory)/payload/zapret/1.10.4"
.tools/dotnet/dotnet.exe run --project tests/broker-service -c Release
.tools/dotnet/dotnet.exe run --project tests/app-update -c Release
.tools/dotnet/dotnet.exe run --project tests/tg-service -c Release -- runtime/python/python.exe
runtime/python/python.exe -m unittest discover -s tests -p tg_test.py
```

Изолированные тесты используют временные данные и локальные тестовые процессы. `--network-check`, `--component-smoke` и `--selection-smoke` предназначены для отдельной осознанной проверки сети и установки. Они не входят в обычный запуск приложения.
