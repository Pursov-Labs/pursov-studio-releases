# PURSOV STUDIO

Открытая оболочка для Windows: Zapret и TG WS Proxy, один переключатель подключения, понятные состояния и обновления после подтверждения пользователя.

Сетевые компоненты основаны на [Flowseal / zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [Flowseal / tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Оригинальный код оболочки доступен под [MIT](LICENSE); лицензии и авторство сторонних компонентов сохранены.

- [Выпуски и установщики](https://github.com/Pursov-Labs/pursov-studio-releases/releases)
- [Что проверено и что ещё предстоит](docs/VALIDATION.md)
- [Компоненты и лицензии](THIRD_PARTY_LICENSES.md)

Версия [2.0.2](https://github.com/Pursov-Labs/pursov-studio-releases/releases/tag/v2.0.2) опубликована в основном канале обновлений для пилотной передачи знакомым. Манифест обновления подписан; первичный MSI не имеет доверенной подписи издателя Windows.

На Windows 11 проверены миграция старой установки, автоматическая загрузка 2.0.2, установка через кнопку, перезапуск без повышения прав и восстановление подключения. Установка, принудительный откат, обновление и удаление также прошли на изолированной Windows Server 2025. Чистые целевые Windows 10/11 и реальные сообщения, звонки и просмотр видео требуют отдельных проверок; подробности — в [отчёте](docs/VALIDATION.md).
