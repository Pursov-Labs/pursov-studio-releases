# PURSOV STUDIO

Открытая оболочка для Windows: Zapret и TG WS Proxy, один переключатель подключения, понятные состояния и обновления после подтверждения пользователя.

Сетевые компоненты основаны на [Flowseal / zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [Flowseal / tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Оригинальный код оболочки доступен под [MIT](LICENSE); лицензии и авторство сторонних компонентов сохранены.

- [Установка, использование и сборка из исходников](README_RU.md)
- [Выпуски и установщики](https://github.com/Pursov-Labs/pursov-studio-releases/releases)
- [Что проверено и что ещё предстоит](docs/VALIDATION.md)
- [Компоненты и лицензии](THIRD_PARTY_LICENSES.md)

Версия 2.0.0 пока распространяется как предварительный выпуск. Первичный MSI не имеет доверенной подписи издателя Windows. Перед массовой передачей нужны проверки чистой установки, обновления и пользовательских сетевых сценариев на целевых Windows 10/11.
